# Background images

Tech-themed backgrounds used on the site (e.g. in `RetroTechBackground`).

- **tech-circuit.jpg** — Circuit board (Unsplash)
- **tech-matrix.jpg** — Binary/code matrix (Unsplash)
- **tech-glows.jpg** — Glowing tech (Unsplash)

You can swap `BG_IMAGE` in `components/RetroTechBackground.tsx` to use `tech-matrix.jpg` or `tech-glows.jpg` for a different look. All images are used at low opacity so the blue theme and overlays remain dominant.
